## Project Overview
This is a 5-page website for EcoClean Solar Solutions, a solar panel cleaning and maintenance company in South Africa.

The site has five pages: Home, About Us, Services & Pricing, Solar Care Hub, and Request Quote.

Part 1 built the HTML structure. Part 2 adds CSS styling and responsive design so the site works on computers, tablets, and phones.

## Responsive Design
The site uses two breakpoints.

Tablet: 768px and below. Navigation wraps, font sizes reduce, layout adjusts.

Mobile: 480px and below. Everything stacks in one column, navigation stacks, font sizes get smaller, images scale down.
